# Java Day 44 - Student Course Registration System

## Description
A Java-based Student Course Registration System that manages student course registrations and stores information in a CSV file.

## Features
- Register students for courses
- Display all registrations
- Search registrations by student name
- Prevent duplicate registrations
- Display total registrations
- Save records in a CSV file

## Files
- `Main.java` - Main Java program
- `registrations.csv` - Registration data

## How to Run
1. Keep both files in the same working directory.
2. Compile:

`javac Main.java`

3. Run:

`java Main`

## Concepts Used
- OOP
- Classes and Objects
- Constructors
- ArrayList
- Loops and Conditions
- CSV File Handling
